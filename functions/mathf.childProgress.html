    Function childProgress

    • childProgress(
          progress: number,
          start: number,
          end: number,
          noClamp?: boolean,
      ): number

      Given a progress (a value that ranges from 0 to 1), this method allows you to create a child progress based on the parent progress.

      Imaging the following progress.

      Parent progress
      0 -----0.2------0.4-------0.6-------0.8------1

      Child progress
             0.2----------------0.6

      mathf.childProgress(parentProgress, 0.2, 0.6)

      If you have a parent progress runnning from 0 to 1 and you wanted your child progress to start at 0.2 and end at 0.6.

      Given the parent progress, this method would return:

      Parent progress        Output
      0            --------->   0
      |
      0.2          --------->   0
      0.3          --------->   0.25
      0.4          --------->   0.5
      0.5          --------->   0.75
      0.6          --------->   1
      0.7          --------->   1
      |
      1            --------->   1

      Parameters

      • progress: number
      • start: number

        The starting value of the child progress. Value between 0 and 1.

      • end: number

        The end value of the child progress. Value between 0 and 1.

      • noClamp: boolean = false

      Returns number
